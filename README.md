# World Insights Dashboard

Painel interativo do Power BI para analisar indicadores de corrupção, felicidade, expectativa de vida e população em 65 países e 6 continentes. 
Fornecer uma visão global dos países, permitindo comparações entre indicadores econômicos e sociais por meio de visualizações interativas.

## Principais Indicadores

- PIB
- População
- Índice de Felicidade
- Nível de Corrupção
- Expectativa de Vida

##Informações consultada

-Continente
-Idioma
-Capital
-Moeda

## Tecnologias

- Power BI
- Power Query
- DAX
